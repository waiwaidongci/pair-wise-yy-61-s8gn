# pair-wise-yy-61 航空器定检工作包执行与放行审阅平台

支持工卡依赖、测量值容差校验、离线暂存、冲突提交提示、分阶段签字、版本差异和放行锁定。超差项目必须由授权人员处理后才能继续。

## 离线修订合并

机库内网易断，工卡可离线执行，联网后逐字段合并到服务器：

- **字段级版本化**：测量值、发现项、见证确认、阶段签署每个字段都记录修订号与来源（服务器 / 本地草稿 / 超差授权 / 阶段签署）。
- **逐字段三方合并**：网络恢复后按字段合并，不再整卡拒绝；服务器已更新的字段若本地也改过，登记为冲突。
- **超差授权绑定版本**：授权记录与工卡版本一起生效，版本变化即作废旧授权，工卡回到待授权。
- **后到方看差异再决定**：冲突时弹出差异对比，后到方逐字段选择保留本地或采用服务器，未查看差异前不覆盖先到数据。
- **旧草稿升级**：没有修订号的旧草稿按当前服务器版本升级，来源标记为服务器基线。
- **写入失败保留 + 幂等重试**：写入失败时原草稿与待合并改动原样保留，重试使用同一客户端幂等键，服务器去重保证只生效一次。
